<objective>
Lay the persistence foundation the unified tile model needs: a stable-but-random loopback port
(D-05), a per-install secret path segment (D-06), and a persisted copy of the operator's
`/map/style-sources` response (D-09).

Purpose: RESEARCH.md 4.5 establishes that MapLibre's ambient cache keys on `resource.url` — the
loopback URL — so today's ephemeral bind orphans the entire tile cache on every cold start.
That is latent waste today; once every online tile also routes through the proxy it becomes a
real data and battery regression (ROADMAP success criterion 5). Separately, the proxy cannot
build a redirect target without the operator's upstream tile template, and an offline cold start
has to know it without a network call.

This plan writes and persists those values. Plan 03 consumes them. Nothing here changes any
rendering behavior, so it is safe to run alongside Plan 01's risk gate: criterion 5 needs a
stable port regardless of which recovery mechanism the gate selects.

Output: four new `LocalSettingsEntity` fields, two new service modules, a persisting
`MapStyleSourcesNotifier`, and unit tests for the pure half.
</objective>

split exactly the way `map_cache_path.dart` splits validation from use so the pure half is
unit-testable without a live ObjectBox store.

Pure half:
- `const int kTileProxyPortMin = 49152;` and `const int kTileProxyPortMax = 65535;` — the IANA
  dynamic/private range. Document that the range is deliberately the same one an ephemeral bind
  would have drawn from, so persisting a value out of it is no more guessable than today's
  behavior (D-05).
- `class TileProxyIdentity` with `final int port` and `final String secret`, a const constructor,
  and `==`/`hashCode` so tests can compare instances.
- `TileProxyIdentity mintTileProxyIdentity({Random? random})` — takes an injectable `Random`
  defaulting to `Random.secure()`. Port is `min + random.nextInt(max - min + 1)`. Secret is 16
  random bytes rendered as 32 lowercase hex characters (`nextInt(256)` per byte,
  `toRadixString(16).padLeft(2, '0')`). The doc comment must state that `Random.secure()` is
  mandatory here and that a non-secure `Random` is accepted only for tests.
- `bool isValidProxySecret(String secret)` — true only for `RegExp(r'^[0-9a-f]{32}$')`. This is
  the gate Plan 03 uses before accepting a persisted secret and before comparing a request's
  first path segment, so a corrupted or truncated persisted value can never become a live route
  prefix.

Store-backed half (both functions take a `Store` and use `store.box<LocalSettingsEntity>()`):
- `TileProxyIdentity resolveTileProxyIdentity(Store store)` — read the single settings row
  (`getAll().firstOrNull ?? LocalSettingsEntity()`); if `tileProxyPort` is within
  `[kTileProxyPortMin, kTileProxyPortMax]` **and** `isValidProxySecret(tileProxySecret)`, return
  that identity unchanged (this is the D-05/D-06 stability guarantee — a valid persisted identity
  is never re-minted). Otherwise mint a fresh one, write both fields onto the same entity
  instance, `put` it, and return the minted identity. Never mint the port and secret
  independently — a half-valid row is replaced wholesale.
- `void persistTileProxyPort(Store store, int port)` — overwrite only `tileProxyPort` on the
  existing row and `put`. Plan 03 calls this when the persisted port turns out to be occupied at
  bind time; the secret must survive that rebind unchanged, since re-minting it would churn the
  glyph/sprite cache keys for no reason.

Create `app/test/services/tile_proxy_identity_test.dart` covering the pure half only (no
ObjectBox store — this repo's tests deliberately avoid live stores; see the
`splitRegionTilePaths` precedent in `test/services/tile_repository_manager_test.dart`):
minted ports always fall inside the constant range across many draws with a seeded
`Random(1234)`; minted secrets always satisfy `isValidProxySecret`; minted secrets are 32

the secret is not a constant); `isValidProxySecret` rejects the empty string, a 31-char string, a
33-char string, an uppercase-hex string, and a string containing `/` or `.` (path-segment

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-04 | Spoofing | `mintTileProxyIdentity` | mitigate | Port drawn from the IANA dynamic range and secret drawn as 16 bytes of `Random.secure()`, rendered as 32 hex chars (128 bits). Persisting a *random* port keeps D-05's stability without recreating the guessable-fixed-port risk `tile_proxy_server.dart:29-32` warned about. |
| T-39-05 | Tampering | `tileProxySecret` read back from storage | mitigate | `isValidProxySecret` anchors `^[0-9a-f]{32}$`, so a truncated, uppercase, or separator-bearing persisted value is rejected and the identity is re-minted rather than becoming a live route prefix containing `/` or `..`. |
| T-39-06 | Tampering | `mapStyleSourcesJson` / `demTileTemplate` read back from storage | mitigate | `readPersistedMapStyleSources` is `try/catch`-wrapped and returns `null` on any malformed payload. This plan performs no URL validation on purpose — Plan 03 revalidates every template through `isSafeRedirectTarget` at the point of use, so persisted data is never trusted as a URL by whoever reads it. |
| T-39-07 | Information Disclosure | `tileUrl` carries the operator's `PROTOMAPS_API_KEY` query parameter | accept | The same value is already substituted into every composed style JSON held in memory today; writing it to app-private ObjectBox storage is the same trust class and no new exposure. | T-39-08 | Denial of Service | additive ObjectBox migration | mitigate | Every new field is defaulted and no existing property is renamed or dropped; the verify step asserts the three pre-existing properties survive and that `retiredPropertyUids` gains nothing, so an installed app cannot fail to open its store after upgrade. |
| T-39-SC | Tampering | npm/pip/cargo/pub installs | accept | This plan adds zero package-manager dependencies (`pubspec.yaml` is not in `files_modified`). No legitimacy audit is required because no install task exists. |
