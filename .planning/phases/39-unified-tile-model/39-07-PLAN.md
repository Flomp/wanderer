<objective>
Delete `NavigationScreen.isOffline` outright — the parameter, both compose branches, both
`ref.listen` forks — and remove every upstream value that existed only to feed it (D-16, D-01).

Purpose: `navigation_screen.dart` is the exact twin of `trail_map.dart`; RESEARCH.md 2 and
39-PATTERNS.md both classify them as one fork implemented twice, and the same "pinned to whatever
mode it was born in" defect reproduces here at lines 1339-1341. Deleting the parameter here is
half of ROADMAP criterion 3. The plumbing that computed the flag — a `bool` slot in the
`/navigate` route's `extra` record, an `isOffline` key in the `/record` route's `extra` map, and
two resume-time reachability probes whose results were only ever used to pick a style path — goes
with it, because `main.dart`'s own comment states the flag "only selects the map style path".

Runs in parallel with Plan 06, which performs the identical deletion in `TrailMap`; the two plans
share no file.

Output: a `NavigationScreen` with one style path, a 3-slot navigate `extra`, and two live
connectivity reads replacing the two non-style uses of the old flag.
</objective>
