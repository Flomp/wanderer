<objective>
Retire everything the unified path made dead: the second style-JSON provider and its sentinel
helpers (D-10), the offline glyph/sprite paths provider, and the legacy `rewriteStyleForOffline`
N-cell duplication path with its spike harness (D-17). Rename the transform's file and test to
match what it now is.

Purpose: ROADMAP criterion 3 is "the split is gone, not patched". After Plans 06 and 07 the
forked providers and the legacy transform have no production caller, and `rewriteStyleForOffline`'s
own doc comment has marked itself as pending cleanup since Phase 15. Leaving a second style
provider and a second style transform in the tree would leave the fork one import away from
coming back, and would leave a file named `offline_style_rewriter.dart` describing a mode the
codebase no longer has — the same false-premise hazard D-14 forces `MainActivity.kt` to fix.

Output: one style provider, one style transform, correctly named files, and a smaller test tree.
</objective>
