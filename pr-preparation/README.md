# Ausstehende Aufgaben

- [ ] Den begrenzten Umfang P0–P2 der [Föderationsspezifikation](federation-spec/README.md) mit den Maintainern abstimmen.
- [ ] [Offene Entscheidungen](federation-spec/07-decisions.md) klären; zuerst D-01 bis D-03: Umfang der Föderation, Vollständigkeit der Synchronisierung und Verhalten bei Ausfällen.
- [ ] Für P1 vorhandene Regressionstests als wiederverwendbare Fixtures mit echtem Schema und Router aufbereiten.
- [ ] Für P2 Allowlist-Import und isolierte Response-Projektion in kleine PRs gemäß [Umsetzungsplan](federation-spec/06-rollout-plan.md) zerlegen und mit den dafür ausgewählten [Abnahmeszenarien](federation-spec/05-acceptance-tests.md) prüfen.
- [ ] Nach P2 entscheiden, ob einzelne Ausbauoptionen aus P3–P8 Nutzen und Aufwand rechtfertigen.
